// architecture

Classic five stages — fetch, decode, execute, memory, writeback — over a Harvard memory architecture, with a hazard control unit handling stalls and forwarding. The full RV32I base integer instruction set is supported.

// verification

A core that runs your own handwritten tests proves nothing. I ran the RISCOF compliance framework against the Spike reference model, co-simulating both and comparing signatures through a custom Python wrapper I wrote to drive the flow. Result: 100% architectural compliance on the base integer set.

// physical design

Synthesized and placed through LibreLane targeting Sky130, producing a verified GDSII layout. I built the same design twice to see the PPA trade-off honestly: high-speed standard cells hit 95.2 MHz at 0.551 mm², while a high-density variant gives up a third of the frequency for a fifth of the area at 58.8 MHz and 0.427 mm². Both close with clean STA and LVS signoff.
