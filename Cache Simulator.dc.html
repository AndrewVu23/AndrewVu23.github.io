module cache_simulator

A cache you can argue with

Textbooks assert that associativity stops paying off around eight ways. I wanted a tool that would let me sweep the parameter and see the curve flatten myself.

// what it models

geometry configurable set count, associativity, line size
write policies 4 — through / back × allocate / no-allocate
replacement LRU, FIFO, tree-based PLRU, random — pluggable behind one interface
reporting 3C’s miss classification, AMAT profiling

Replacement policies sit behind a common interface, so adding a fifth is one file and no changes to the cache itself. Behaviour is pinned by a doctest unit-test suite rather than by me eyeballing hit rates.

// the sweep

The part I actually built it for: a design-space sweep that runs one workload across a grid of cache configurations and emits CSV, which a matplotlib script turns into miss-rate-versus-associativity and miss-rate-versus-size curves. The knee in those curves is the whole point.

// next

Single level for now. Multi-level with inclusion policies is the obvious extension, and it would let me sanity-check the L2 write behaviour I have been chasing in Accel-Sim against a model I fully control.
